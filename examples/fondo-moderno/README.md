# Fondo Moderno — distribution repo

Prepared 2026-09-25.

This repo is a **curated submission system**, not a bulk backlink bot. It separates:
1. product/startup launch platforms;
2. web-design galleries;
3. maker communities;
4. architecture/editorial pitches;
5. company-profile databases.

The source project is **Fondo Moderno**, currently described on its own site as an independent platform for documenting, preserving and reactivating modern architecture, beginning in Mexico City. The live site currently includes a growing building index, architects, curated city walks/guides and researched color systems.

## Start here

- `AGENTS.md` — rules for Codex/Claude-style browser agents.
- `projects/fondo-moderno/profile.md` — approved factual product profile.
- `projects/fondo-moderno/copy.md` — reusable copy variants by field length.
- `projects/fondo-moderno/assets/README.md` — asset checklist.
- `data/platforms.csv` — researched candidate set with priority and evidence.
- `data/submissions.csv` — run tracker.
- `playbooks/` — platform-specific instructions for the first wave.
- `MANUAL_REVIEW.md` — channels that should **not** be automated.

## Operating principle

Do **not** submit to every directory just because it exists. Work P0 first. After each live placement:
- record the public URL;
- verify it logged out;
- inspect whether the outbound link is a normal link / nofollow / sponsored;
- check whether the listing is indexed after a reasonable interval;
- keep only channels that produce either relevant discovery, a durable indexed page, or a meaningful referral signal.

A directory that requires false company facts, fake reviews, paid actions, manufactured votes, or an irrelevant product category is `not_fit`, not a puzzle to bypass.
