# Assets to prepare before the first run

Create/export these from the live product. Do not fabricate UI screens.

## Required core set
- `logo-square.png` — 512×512 or larger square master.
- `thumbnail-240.png` — 240×240 for Product Hunt (recheck current limit at submission).
- `hero-home-1600x900.png` — homepage / main discovery experience.
- `guide-1600x900.png` — one curated architectural walk.
- `building-1600x900.png` — one strong building page.
- `colors-1600x900.png` — color research page if visually strong.
- `mobile-home.png` — current mobile homepage.
- `og-image.jpg` — social share image if the site does not already have one.

## Screenshot rules
- Use only current live UI.
- No fake device frames unless the platform explicitly wants them.
- Keep the first image understandable without reading tiny labels.
- Prefer one idea per screenshot.
- Check copyright/credit requirements for any architectural photography visible in the screenshots.

## Before launch
- Confirm favicon and social preview render correctly.
- Confirm the English homepage and at least 2–3 core routes work without login.
- Confirm About page is public.
- Confirm analytics can identify UTM referral traffic.
