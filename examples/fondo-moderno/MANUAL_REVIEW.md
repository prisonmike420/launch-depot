# Manual review lanes

These channels should not be run as blind form automation.

## Sidebar
Self-submission is allowed, but selection is editorial. Their guidelines favor new, high-effort design resources and discourage generic promotional content. Submit the project as a useful architecture/design resource.

## Behance
Create an actual case study, not a directory card. Suggested structure:
1. What Fondo Moderno is
2. Information architecture / database logic
3. Buildings and architects
4. City walks
5. Color research
6. Mobile / desktop views
7. Link to the live site

A human should review image credits and publish.

## Peerlist
A launch is attached to a real maker profile. Prepare the project card, but do not fabricate a social presence or automate engagement.

## Hacker News
Do not use Show HN for Fondo Moderno in its present form: Show HN explicitly excludes curated lists and other reading material. A normal HN submission can be considered if there is a specific intellectually interesting angle (for example the research/data model behind the architecture index). Community participation must be human.

## ArchDaily
The built-project submission path is for built projects completed after 2014. Fondo Moderno itself is not such a project. If pitching, use the publication/news/article route and write a genuine editorial pitch.

## Divisare
Only relevant if Fondo Moderno has an original architecture project or photo report that meets Divisare's submission requirements. Do not submit the platform itself as if it were an architectural project.

## Paid decisions
BetaList, Awwwards and DesignNominees require a human decision before payment. Never purchase through an agent.
