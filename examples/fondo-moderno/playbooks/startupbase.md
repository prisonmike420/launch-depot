# StartupBase
Source: https://startupbase.io/about
Checked: 2026-09-25

Fit: good if positioned as a working digital product.

Prepare: name, URL, tagline, description, tags, logo, >=1 screenshot.

Workflow:
1. Search for existing Fondo Moderno listing.
2. Submit canonical URL and product name.
3. Review any auto-imported copy; replace with approved factual copy.
4. Use architecture / travel / design / discovery-adjacent tags if actually available.
5. Choose free queue unless human explicitly approves a paid plan.
6. Do not add badges or launch promotions without approval.
7. Track review and public URL.
