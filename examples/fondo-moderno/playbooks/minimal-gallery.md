# Minimal Gallery
Sources:

Curated design gallery. User submissions are explicitly supported.

Workflow:
1. Submit canonical URL via current submission form.
2. Provide accurate credits/comments only.
3. Do not exaggerate platform/technology used.
4. Wait for editorial review.
5. If accepted, record gallery page + newsletter appearance if observed.
