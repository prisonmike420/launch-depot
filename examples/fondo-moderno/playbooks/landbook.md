# Landbook
Source: https://land-book.com/submission-guidelines
Checked: 2026-09-25

Free curated web-design submission. No fee. Anyone can submit; not every submission is accepted.

Workflow:
1. Confirm the site is visually launch-ready.
2. Submit canonical homepage.
3. Mark authorship truthfully.
4. Use design credits only if verified.
5. Submit once; do not resubmit duplicates.
6. If accepted, record gallery URL and backlink.
