# Launching Next
Source: https://www.launchingnext.com/submit/
Checked: 2026-09-25

Free submission exists; paid express review is optional.

Form includes:
- startup name
- URL
- 5–8 word headline
- description up to 2,500 chars
- 5–10 tags
- classification including side project / bootstrapped startup

Workflow:
1. Submit through free route.
2. Use 'side project' or 'bootstrapped startup' only if human confirms that representation.
3. Decline paid express by default.
4. Record `submitted`; later verify if a permanent profile is published.
