# Launch Depot — submission copy

## Tagline
Relevance-first product distribution for AI agents

## Short
Launch Depot is an open-source Agent Skill that researches, prepares, submits and verifies relevant product listings without turning distribution into bulk backlink spam.

## Medium
Launch Depot is an open-source Agent Skill and skills-only plugin for product distribution. It researches current launch directories, skill registries, design galleries and editorial channels, ranks them by fit, prepares submission copy and assets, tracks approvals, and verifies which placements actually go live.

## Long
Launch Depot is an open-source Agent Skill for building and running relevance-first product distribution workflows. Give it a real product or website and it creates a factual project profile, researches current submission channels, separates safe automation from editorial or human-review paths, prepares copy and assets, tracks every submission state, and verifies public placements after publication. It is designed to avoid the common failure mode of directory automation: inventing claims, misclassifying a product, paying or adding reciprocal badges without approval, or equating hundreds of low-value submissions with useful distribution.

## Skill-directory description
Research, prioritize, prepare, submit and verify high-signal product distribution across launch directories, skill registries, design galleries and editorial channels.

## Developer-tool description
A portable Agent Skill that turns product-directory research and submission into a tracked, relevance-first workflow with explicit human approval boundaries.
