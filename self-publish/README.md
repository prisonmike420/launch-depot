# Launch Depot self-publishing

This folder is Launch Depot using its own workflow on itself.

## Goal
Distribute the repository and its `launch-depot` Agent Skill only where the project naturally fits.

## Order
1. skills.sh — canonical CLI ecosystem; automatic indexing after a real install.
2. GitHub-crawled skill indexes — SkillsMP and similar.
3. Free skill-specific directories with an explicit author submission path.
4. Curated GitHub catalogs via pull request.
5. General product-launch directories only after the skill has a stable public listing and real users.
6. Paid listings only after explicit human approval.

## Human boundaries
Forms that require account sign-in, email ownership, CAPTCHA, acceptance of terms, paid checkout, or public author identity remain human-review actions.

## Verification
A target is only marked `live` after its public listing is accessible and points back to the canonical GitHub repository or skill.
