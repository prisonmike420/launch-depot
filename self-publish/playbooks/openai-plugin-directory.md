# OpenAI universal plugin directory

Checked: 2026-09-25
Official docs:
- https://developers.openai.com/plugins/build/plugins
- https://developers.openai.com/plugins/guides/submit-claude-plugin

Launch Depot uses the portable plugin layout:
- root `plugin.json`;
- root `skills/launch-depot/SKILL.md`;
- supporting skill assets/references under the skill directory.

The public ChatGPT/Codex plugin directory uses a submission/review flow. A GitHub repo marketplace is a separate distribution mechanism and does not itself publish the plugin to the universal directory.

Human boundary:
Public submission requires the OpenAI plugin submission surface and review fields. Do not claim public-directory availability until approval is visible.
